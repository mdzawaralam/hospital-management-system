Please give me a layered architecture for Nodejs, need to deelope APIs from scratch.

Below are the requirements.
Roles:
a. Admin
b. Doctor
c. Receptionist
d. Patient

Admin will be by default user in the database. Admin will register Doctor and Receptionist, after successfully registration they will get successfull message with login details in mail(will use RabbitMQ). Receptionist will register Patient, patient will also get message with login details in mail (will use RabbitMQ).
A Patient will visit the hospital, first he will come to reception, the Receptionist register the Patient and assign the appropriate doctor as per disease and doctor availability.

The doctor will login and see the assigned patient, doctor will treat the patient. 
Admin can see all doctor, receptionist and patient details also can add message or delete any user
Receptionist can see only patient details and associated doctor
Doctor can see all associated patient and can add message  or can delete any patient
patient can see own profile details including treatment details

Need to do:
- JWT token based authentication
- Role based authorization
- prisma client version6 will use

postgresql database will use.
RabbitMQ will use for sending mail after login successfull

Here is our initial API contract. All routes are prefixed with /api.
Method				Endpoint										Access
POST				/auth/login										Public
POST				/auth/refresh									Refresh-token policy
POST				/auth/logout									Authenticated
POST				/admin/doctors									Admin
POST				/admin/qualification							Admin
GET					/admin/doctors									Admin
POST				/admin/receptionists							Admin
GET					/admin/users									Admin
PATCH				/admin/users/:id								Admin
DELETE				/admin/users/:id								Admin, preferably soft delete
POST				/receptionist/patients							Receptionist
GET					/receptionist/patients							Receptionist
POST				/receptionist/appointments						Receptionist
GET					/receptionist/appointments						Receptionist

GET					/doctor/appointments							Doctor
POST				/doctor/treatments								Doctor
